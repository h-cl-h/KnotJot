# Contributing

Read each app's DEVELOPMENT.md before changes. Preserve the apps/product/version/source layout and shared build inputs. Keep executable names, namespaces, formats and connection identities compatible.

Write every user README as a complete English edition followed by a complete Chinese edition, with equivalent content. Focus on installation, first use, daily workflows, saving/syncing and troubleshooting. Put build and implementation details in DEVELOPMENT.md. Explain changed source functions in English followed immediately by Chinese. Run the applicable existing checks and update bundled documentation before release.

## 中文

修改前阅读对应 DEVELOPMENT.md，保留产品目录、共享输入及程序身份、命名空间、格式和连接兼容性。README 先完整英文、后完整中文，两版对等；重点介绍安装上手、常用操作、保存同步及问题处理，开发细节单独放入 DEVELOPMENT.md。修改的源码函数使用英文后中文说明，执行现有针对性检查并更新随附文档。
